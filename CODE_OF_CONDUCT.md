# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, criticise results and code rather than people, and keep discussion
on topic. Harassment of any kind is not tolerated.

To report a problem, open a private report through GitHub's "Report content" link, or use the contact listed
on the maintainer's GitHub profile. Reports are handled confidentially.
